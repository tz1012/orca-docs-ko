Orca 모바일 앱을 데스크톱에 페어링하여 에이전트를 모니터링하고 전화기에서 작업 트리를 해제하세요.

Orca 모바일 컴패니언은 데스크톱 Orca과 쌍을 이루는 iOS/Android 앱으로, 실행 중인 에이전트에 대한 읽기 전용 보기(에이전트 상태, 최근 터미널 스크롤백, 전화에서 실제로 원하는 제어(프롬프트에 응답, 작업 트리 휴면, 소스 제어 검토, 에이전트 계정 전환))를 제공합니다. 페어링은 일회성이며 데스크탑은 항상 정보의 소스입니다.

Orca 모바일 — 상담원 상태, 스크롤백 및 전화기를 통한 빠른 응답.

베타

모바일 컴패니언은 베타 버전입니다. [App Store](https://apps.apple.com/us/app/orca-ide/id6766130217)에서 iOS를 설치하거나, ​​[TestFlight 미리보기 채널](https://testflight.apple.com/join/YjeGMQBA)에 가입하거나, [현재 APK 0.0.27](https://github.com/stablyai/orca/releases/download/mobile-android-v0.0.27/app-release.apk)에서 Android를 설치하세요.

## 모바일에서 할 수 있는 일

- 모든 작업 트리, 해당 에이전트 및 현재 상태(작업/완료/입력 대기)를 확인하세요. 모바일은 연결된 모든 호스트(로컬 데스크톱 및 원격 Orca 서버)의 작업 트리를 단일 보기에 나열하므로 호스트 간 전환 시 장치 변경이 필요하지 않습니다.
- 깊게 중첩된 경로를 포함하여 모바일에서 작업 공간의 전체 파일 트리를 탐색하므로 데스크탑을 기다리지 않고 어떤 파일로든 이동할 수 있습니다.
- 최근 터미널 스크롤백을 수화하여 상담원이 수행하거나 요청한 내용을 읽을 수 있습니다.
- 모바일 단말기 보기에서 텍스트를 선택하고, 복사하고, 붙여넣습니다. 선택하려면 길게 누르고, 답장에 다시 붙여넣으려면 시트를 공유하세요.
- `Tab` 및 `Shift+Tab`을 포함하여 휴대폰 키보드에서 어색한 키에 대해 터미널 액세서리 행을 사용하거나, 입력한 각 문자가 활성 터미널로 바로 이동해야 하는 경우 `Live`(실시간)로 전환하세요.
- 상담원이 입력 대기 중일 때 짧은 답장(`continue`, `yes`, 자유 텍스트)을 보내거나, 사진이나 파일을 첨부하거나, 마이크를 탭하여 응답을 받아쓰세요. `Live`(실시간) 모드에서는 Return 키를 누르지 않고도 받아쓰기 텍스트가 활성 터미널에 삽입됩니다.
- 휴대폰에서 반응형 페이지를 확인해야 하는 경우 `Web`(웹) 또는 `Mobile`(모바일) 보기에서 브라우저 세션을 엽니다.
- 작업 트리에 대한 오픈 소스 제어를 통해 변경된 파일을 검토하고, 스테이지 또는 언스테이징하고, 휴대폰에서 커밋할 수 있습니다.
- 활성 에이전트 계정을 전환하고 이동 중에도 사용량/비율 제한 상태를 확인하세요.
- 에이전트가 완료되면 [데스크톱 알림](/orca-docs-ko/docs/notifications/)을 미러링하여 푸시 알림을 받습니다.

모바일 앱은 의도적으로 전체 편집기가 아닙니다. 이미 실행 중인 데스크톱에 대한 원격 제어입니다.

## 페어링

1. 데스크톱의 계정/상태 메뉴에서 Orca의 페어링 흐름을 엽니다. Orca는 일회성 페어링 코드를 표시합니다.
2. 모바일에서 Orca 컴패니언 앱을 열고 `Pair`(페어링)을 선택한 다음 코드를 붙여넣습니다. (데스크톱에서 딥링크를 따라 모바일 페어링 화면으로 직접 이동할 수도 있습니다.)
3. 페어링 교환은 데스크톱과 휴대폰 간에 직접 이루어집니다. Orca는 페어링된 전화기에 대해 결과 장치 토큰을 사용합니다.

데스크톱 앱을 닫으면 연결이 끊어지며 클라우드 릴레이가 없습니다. 데스크톱을 다시 열면 전화기가 자동으로 다시 연결됩니다.

## 계정 전환기

모바일 앱은 비활성 계정에 대한 인라인 사용을 포함하여 데스크톱 상태 표시줄과 동일한 계정 전환기를 노출합니다. 여기에서 전환하면 페어링된 데스크톱이 켜집니다.

## 모바일에서 소스 제어

작업 트리 세션에서 분기 아이콘을 탭하여 소스 제어를 엽니다. 소규모 후속 작업에 사용하세요. 분기 상태를 확인하고, 변경된 경로를 검사하고, 파일을 준비하거나 준비 해제하고, 준비된 세트가 준비되면 커밋하세요. 분기에 이미 GitHub 풀 요청이 있는 경우 새 PR을 생성하는 대신 빈 PR 상태에서 `Link an existing PR`(기존 PR 연결)을 사용하여 연결하세요.

## 모바일 브라우저 보기

모바일 브라우저 창에는 `Web / Mobile`(웹/모바일) 스위치가 있습니다. 일반 페이지를 보려면 `Web`(웹)을 사용하고, 페어링된 데스크톱 브라우저에 휴대폰 크기의 반응형 뷰포트를 요청하려면 `Mobile`(모바일)을 사용하세요.

## 터미널 설정

모바일 단말기에는 전용 `Terminal settings`(터미널 설정) 화면(설정 → 터미널)이 있습니다.

- `Text size`(텍스트 크기) — WebView가 너비에 맞춤 위에 적용되는 50%~200% 기준 확대/축소입니다. 터미널의 핀치 투 줌(Pinch-to-Zoom)은 동일한 사전 설정으로 스냅되고 지속됩니다. 이 설정은 장치별로 적용되며 데스크톱 터미널을 변경하지 않습니다.
- `Autocomplete & autocorrect`(자동 완성 및 자동 수정) — 기본적으로 꺼져 있으므로 OS는 명령 모음의 명령, 플래그 또는 경로를 다시 쓰지 않습니다. 전화 스타일로 타이핑하려면 이 기능을 켜세요. 라이브 키보드 캡처 입력은 여전히 ​​어느 쪽이든 원시 키 입력을 스트리밍합니다.

## 문제 해결

- `Stuck spinner on a worktree`(작업 트리의 회전자가 멈췄습니다) — 전화기는 데스크톱 에이전트 프로세스에서 하트비트를 추적합니다. 데스크톱에는 유휴 상태라고 표시되지만 전화기에는 작동 중인 것으로 표시되면 작업 트리 행을 강제로 새로 고쳐 상태를 동기화하세요.
- `Pairing fails`(페어링 실패) — 데스크톱과 휴대폰이 동일한 Orca 계정에 로그인되어 있는지 확인하세요. 페어링 코드는 몇 분 후에 만료됩니다. 화면에 앉아 있었다면 새로운 것을 생성하십시오.
