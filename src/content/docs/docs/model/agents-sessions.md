상태 점, 재시작 칩, 에이전트 세션의 수명 주기입니다.

`agent session`(에이전트 세션)은 하나의 작업 트리에 있는 하나의 터미널에서 실행되는 하나의 CLI 에이전트입니다. Orca은 수명 주기를 추적하므로 확인하기 위해 각 탭을 클릭할 필요 없이 어떤 세션이 작동 중이고 어떤 세션이 유휴 상태인지 항상 알 수 있습니다.

모든 작업 트리 카드의 인라인 에이전트 상태 — 작업 중에는 노란색, 완료되면 녹색

## 상태 표시기

에이전트 탭과 작업 트리 행은 다음과 같은 공통 상태 기호를 사용합니다.

-   **회전 표시기** — 작업 중
-   **황색 물음표** — 사용자를 기다리는 중(권한/입력 필요)이며, 사이드바의 `Needs You`(사용자 확인 필요) 수도 동일한 기호를 사용합니다.
-   **에메랄드색 체크 표시**(대시보드) 또는 **에메랄드색 점**(사이드바) — 완료/조용히 활성 상태
-   **빨간색 점** — 차단됨, 중단됨 또는 실패
-   **회색 점** — 유휴 상태
-   **표시기 없음** — 인식된 에이전트 CLI가 아닌 일반 셸

상태는 터미널의 OSC 제목 시퀀스와 에이전트 후크에서 감지하며, Claude Code, Codex 및 여러 다른 에이전트가 이를 내보냅니다.

## 상담원 대시보드

**`Settings → Experimental → Agent Dashboard`(설정 → 실험 기능 → 에이전트 대시보드)**를 켭니다. Orca은 왼쪽 사이드바에 **`Agent Dashboard`(에이전트 대시보드)** 항목을 추가합니다. 이 항목은 여러 작업 트리의 에이전트를 보여 주는 칸반 보드입니다.

### 열

-   **`Needs You`(확인 필요)** — 권한이나 질문에 대한 응답을 기다립니다.
-   **`Working`(작업 중)** — 현재 실행 중입니다.
-   **`Done`(완료)** — 완료되었지만 아직 검토할 수 있는 세션입니다.
-   **`Idle`(유휴)** — 약 30분 동안 완료를 보고하지 않은 조용한 에이전트입니다. **기본적으로 숨겨집니다.** 동일한 `Experimental`(실험 기능) 설정에서 **`Show idle agents`(유휴 에이전트 표시)**를 활성화합니다. 창 내부 보기와 팝아웃 보기는 동기화됩니다.

### 열기 방식

사이드바 옆의 **`In-window`(창 내부)** 보드 또는 별도 창의 **`Pop-out`(팝아웃)**으로 엽니다.

### 검색 및 필터

보드 도구 모음에는 다음 항목이 있습니다.

-   **`Search`(검색)** — 작업 트리, 프로젝트 또는 에이전트 이름으로 검색합니다. 쿼리나 필터가 활성화되면 결과 수가 표시됩니다.
-   **`Filter`(필터)** — **`Project`(프로젝트)**, **`Workspace status`(작업 공간 상태)** 및 **`PR / MR status`(PR/MR 상태)**를 다중 선택합니다. 상태는 `Open`(열림), `Draft`(초안), `Merged`(병합됨), `Closed`(닫힘), `No review`(리뷰 없음)입니다.
-   제거 가능한 필터 칩과 **`Clear all filters`(모든 필터 지우기)**를 제공합니다.

### 카드

-   **`Header`(헤더)** — 에이전트 아이콘, 세션 **대화 이름**(변경한 이름, 생성된 제목 또는 에이전트 세션 제목이며, 없으면 작업 트리 이름 사용), 상태 글리프를 표시합니다.
-   **`Preview`(미리 보기)** — 사용 가능한 경우 마지막 사용자/에이전트 메시지를 표시하고, 없으면 작업 요약을 표시합니다.
-   **`Footer`(바닥글)** — 프로젝트 아이콘, 헤더에 세션 이름이 이미 표시된 경우 작업 트리 이름, 경과 시간, 가능한 경우 캐시된 리뷰 상태를 표시합니다. 작업 공간 상태는 도구 모음 필터에만 유지되며 카드에는 더 이상 작업 트리별 상태 점이 표시되지 않습니다.
-   **`Needs You`(확인 필요)** 카드는 주황색으로 표시되며 대기 중인 질문 요약을 표시할 수 있습니다. **`Done`(완료)** 카드는 녹색으로 표시됩니다. 다른 상태는 중립 색상을 유지하므로 색상은 "여기를 확인"하라는 의미입니다.
-   카드를 클릭하면 해당 에이전트의 활성 터미널을 open/focus합니다.
-   중첩된 Codex/Claude 하위 에이전트는 상위 행 아래에 펼칠 수 있는 하위 항목으로 표시될 수 있습니다.

실험적 보드가 꺼져 있어도 작업 트리 카드에는 같은 글리프를 사용하는 에이전트 행이 인라인으로 계속 표시됩니다. 상태 표시기가 보이지 않으면 해당 세션의 에이전트 CLI가 Orca에서 인식하는 CLI가 아닙니다. 바이너리를 직접 입력하지 말고 에이전트 콤보 상자에서 시작합니다.

## 실행 기본값

Orca은 완전 자율성 권한 플래그가 사전 적용된 지원되는 모든 에이전트를 시작합니다. 즉, Claude와 `--dangerously-skip-permissions`, Codex와 `--dangerously-bypass-approvals-and-sandbox`, Gemini과 `--yolo`, 그리고 선택기. 그 의도는 작업 트리 자체가 샌드박스라는 것입니다. 즉, 에이전트는 흐름을 중단시키는 도구별 승인 메시지 없이 작업을 수행할 수 있습니다.

에이전트에 대해 다른 기본값을 원하는 경우 `Settings → Agents`(설정 → 에이전트)를 열고 에이전트 행을 확장한 다음 해당 `launch arguments`(실행 인수)를 편집하세요. Orca은 재정의를 기억하고 이후 실행 시마다 이를 적용합니다. 되돌리려는 경우 필드 옆에 있는 `Reset`(재설정) 버튼을 사용하면 배송된 플래그를 다시 되돌릴 수 있습니다.

## 칩 재시작

에이전트가 종료되면(클린 또는 충돌) 탭에 `Restart`(다시 시작) 칩이 표시됩니다. 한 번의 클릭으로 동일한 작업 디렉터리로 동일한 에이전트를 재수화합니다. Codex의 재시작 칩은 현재 계정도 보존합니다([핫 스왑 Codex 계정](/orca-docs-ko/docs/agents/codex-hot-swap/) 참조).

## 세션 수명주기

1. `Launch`(실행) — 콤보 상자에서 에이전트를 선택합니다. Orca은 CLI를 생성합니다.
2. `Work`(작업) — OSC 타이틀 업데이트 상태; 터미널 출력은 검색, 복사 및 Ghostty 테마로 스크롤됩니다.
3. `Idle`(유휴) — Orca는 작업 → 유휴 전환을 감지하고 [에이전트 완료 알림](/orca-docs-ko/docs/notifications/)을 발생시킵니다.
4. `Exit`(종료) — 프로세스가 종료됩니다. 재시작 칩이 나타납니다.

정확한 탐지 규칙은 [Orca CLI](/orca-docs-ko/docs/cli/overview/)의 `terminal wait --for tui-idle` 명령을 참조하세요.
