Android에 Orca 모바일을 다운로드하고 설치합니다.

## Orca 모바일 설치

1.  Chrome이나 다른 전체 기능 브라우저에서 [Orca 다운로드 페이지](https://www.onorca.dev/download)를 열고 **`Android`(안드로이드)**를 선택합니다.
2.  다운로드가 완료되면 브라우저의 **`Downloads`(다운로드)** 또는 기기의 **`Files → Downloads`(파일 → 다운로드)**를 연 다음 `app-release.apk`를 탭합니다.
3.  Android의 설치 안내를 따릅니다. 요청이 표시되면 브라우저 또는 Files 앱에만 출처를 알 수 없는 앱 설치를 허용하고, Orca 설치가 끝나면 해당 권한을 다시 끕니다.

## 문제 해결

### 다운로드가 시작되지 않거나 완료되지 않음

1.  링크가 Discord, GitHub 또는 다른 앱 안에서 열렸다면 **`Open in browser`(브라우저에서 열기)** / **`Open in Chrome`(Chrome에서 열기)**를 선택하거나 링크를 복사해 전체 기능 브라우저에서 엽니다.
2.  [Android 다운로드](https://www.onorca.dev/download/started?platform=android)를 다시 시작하고 완료될 때까지 기다립니다.

### Samsung Galaxy: `Auto Blocker`(자동 차단 기능)

Samsung Galaxy에서 **`Auto Blocker`(자동 차단 기능)**가 설치를 차단했다는 메시지가 표시되면 **`Settings → Security and privacy → Auto Blocker`(설정 → 보안 및 개인정보 보호 → 자동 차단 기능)**를 열어 일시적으로 끄고 Orca를 설치한 다음 다시 켭니다. Play Protect는 비활성화하지 않습니다.
