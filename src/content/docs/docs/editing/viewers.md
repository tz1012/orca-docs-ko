Orca에는 대부분의 저장소에서 자주 사용하는 형식을 위한 뷰어가 내장되어 있습니다.

## HTML

로컬, SSH 또는 페어링 런타임의 `.html` 파일을 **`Open in Orca Browser`(Orca 브라우저에서 열기)** 또는 **`Open Preview to the Side`(옆에 미리 보기 열기)**로 엽니다. Orca는 샌드박스 처리된 브라우저 탭에서 문서를 로컬로 렌더링하고 작업 공간의 파일 연결을 통해 파일과 상대 경로 자산을 읽으므로, 데스크톱 파일 시스템을 노출하지 않고도 원격 디자인 문서를 선명하게 표시합니다.

미리 보기는 추가 폴더를 읽기 전에 권한을 요청하며, 해당 탭에는 승인한 폴더만 허용합니다. 외부 HTTP(S) 링크는 확인 후 일반 Orca 브라우저 탭에서 열리며, 문서 미리 보기 안에서는 다운로드가 비활성화됩니다. **`Preview options`(미리 보기 옵션)**에서 디스크의 내용을 다시 불러오거나, 원본 파일을 열거나, 전체 경로 또는 작업 공간 기준 상대 경로를 복사합니다.

미리 보기의 문서 칩은 주소 표시줄 역할도 합니다. 이를 편집하고 웹 URL을 입력하면 해당 탭이 일반 브라우저 탭으로 전환됩니다. 브라우저 탭에서 작업 공간의 HTML 경로를 입력하면 다시 미리 보기로 전환됩니다. 중간에 다른 페이지 기록이 없으면 **`Back`(뒤로)**을 사용해 두 상태 사이를 이동합니다.

페어링 런타임에서는 HTML 파일이 작업 트리 안에 있어야 합니다. 매우 오래된 페어링 서버에서는 바이너리 자산 없이 문서가 렌더링될 수 있습니다. 원격 이미지가 불러와지지 않으면 서버를 업데이트합니다.

## 인어

인어 다이어그램은 마크다운 미리보기 내에서 인라인으로 렌더링됩니다. 독립 실행형 `.mmd` 파일은 pan/zoom를 사용하는 전용 뷰어에서 열립니다.

## PDF

스크롤, 확대/축소 및 텍스트 선택을 지원합니다. 저장소에 체크인된 디자인 문서를 볼 때 유용합니다. Orca는 탭을 전환하거나 앱을 재시작해도 PDF 확대/축소 수준을 기억합니다. PDF 탭에서 다른 탭으로 전환했다가 돌아오면 같은 세션에서 탭을 닫았다 다시 여는 경우를 포함해 스크롤 위치를 복원합니다. 페이지와 페이지 중간 오프셋을 함께 복원하므로 이전 위치로 돌아갑니다. 위치 정보는 세션에서만 유지되며 Orca를 재시작하면 지워집니다.

## 이미지

`.png`, `.jpg`, `.svg`, `.webp`, `.gif`. 이미지 비교 모드는 동일한 파일의 두 버전을 나란히 비교합니다.

## CSV / TSV

`.csv` 및 `.tsv` 파일은 정렬 가능한 열과 빠른 검색 기능이 있는 테이블 뷰어에서 열립니다. 고정 장치, 내보내기 및 리포지토리에 체크인된 모든 표 형식 데이터에 유용합니다. 셀을 직접 편집해야 하는 경우 도구 모음을 사용하여 원시 텍스트 보기로 다시 전환하세요.

## 주피터 노트북

`.ipynb` 파일을 열면 렌더링된 Markdown, 코드 셀 및 저장된 출력을 볼 수 있습니다. 코드 셀을 클릭하면 편집할 수 있으며, Markdown 셀을 두 번 클릭하거나 Enter 키를 누르면 소스를 편집할 수 있습니다. 편집 내용은 nbformat을 유지한 채 노트북 파일에 저장됩니다.

로컬 Python 노트북에서는 **Shift+Enter**로 셀을 실행하고 다음 셀로 이동하거나 **Cmd/Ctrl+Enter**로 현재 셀에 머무릅니다. 처음 실행한 시점부터 탭을 닫을 때까지 Orca는 해당 노트북의 Jupyter 커널을 유지하므로 셀 사이에서 변수가 유지됩니다. 플롯, 리치 출력, 오류 및 실행 횟수가 셀과 함께 표시됩니다. 노트북 헤더에서 **`Run All`(모두 실행)**, **`Interrupt`(중단)**, **`Restart`(재시작)** 또는 **`Clear All Outputs`(모든 출력 지우기)**를 사용합니다.

헤더의 커널 선택기는 인접한 `.venv` 또는 `.conda` 환경을 권장합니다. 다른 Python을 선택하거나 직접 찾아볼 수 있으며, Orca는 해당 노트북의 선택을 기억합니다. Python에는 `ipykernel`과 `jupyter_client`가 필요합니다. `ipykernel`이 없으면 Orca가 설치를 제안합니다. 선택한 Python이 패키지 설치를 차단하는 경우 **`Create .venv`(.venv 만들기)**를 선택해 워크스페이스 환경을 대신 설정합니다. 설정 대화 상자에 진행 상황과 오류가 표시됩니다.

노트북 코드를 실행하기 전에 Orca의 신뢰 확인 메시지를 승인합니다. 노트북을 신뢰하기 전에는 Orca가 워크스페이스 Python 인터프리터를 시작하지 않습니다. SSH 작업 트리의 노트북과 다른 언어의 노트북도 계속 보고 편집할 수 있습니다. 작업 트리에서 노트북을 찾으려면 [파일 탐색기](/orca-docs-ko/docs/editing/file-explorer/)를 참조합니다.
