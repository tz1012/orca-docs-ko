Orca에는 대부분의 저장소에 표시되는 형식에 대한 내장 뷰어가 포함되어 있습니다.

## 인어

인어 다이어그램은 마크다운 미리보기 내에서 인라인으로 렌더링됩니다. 독립 실행형 `.mmd` 파일은 pan/zoom를 사용하는 전용 뷰어에서 열립니다.

## PDF

스크롤, 확대/축소 및 텍스트 선택을 지원합니다. 저장소에 체크인된 디자인 문서를 볼 때 유용합니다. PDF 탭에서 다른 곳으로 전환했다가 돌아오면(같은 세션에서 탭을 닫았다 다시 여는 경우 포함) 페이지와 페이지 내 중간 오프셋까지 스크롤 위치가 복원되므로 이전에 보던 위치로 돌아갑니다. 위치 정보는 세션 동안만 유지되며 Orca을 다시 시작하면 지워집니다.

## 이미지

`.png`, `.jpg`, `.svg`, `.webp`, `.gif`. 이미지 비교 모드는 동일한 파일의 두 버전을 나란히 비교합니다.

## CSV / TSV

`.csv` 및 `.tsv` 파일은 정렬 가능한 열과 빠른 검색 기능이 있는 테이블 뷰어에서 열립니다. 고정 장치, 내보내기 및 리포지토리에 체크인된 모든 표 형식 데이터에 유용합니다. 셀을 직접 편집해야 하는 경우 도구 모음을 사용하여 원시 텍스트 보기로 다시 전환하세요.

## 주피터 노트북

`.ipynb` 파일은 렌더링된 마크다운, 구문 강조 코드 셀, 저장된 출력이 포함된 노트북 뷰어에서 열립니다. 셀을 편집하면 nbformat을 유지하면서 디스크의 `.ipynb`에 다시 기록되므로 diff는 깨끗하게 유지됩니다.

베타

노트북 편집기는 베타로 표시되어 있습니다. 셀 실행 및 더욱 풍부한 출력 렌더링이 아직 해결 중입니다. 저장소의 노트북이 제대로 로드되지 않으면 문제를 신고하세요.
