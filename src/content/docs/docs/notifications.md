Orca은 터미널뿐만 아니라 에이전트를 실행하므로 에이전트가 실제로 끝나는 시기와 일시 중지된 시기를 알 수 있습니다. 알림은 해당 신호를 기반으로 하여 세 명의 상담원을 대기열에 추가하고 자리를 떴다가 첫 번째 상담이 완료되면 돌아올 수 있습니다.

## 에이전트 완료 핑

에이전트가 작업 중에서 유휴 상태로 전환되면 Orca은 알림(시스템 알림, 사운드 및 작업 트리의 칩)을 발생시킵니다.

## 지속적인 벨

헤더 벨은 모든 작업 트리에서 읽지 않은 알림을 표시합니다. 알림을 클릭하면 일치하는 작업 트리 및 창으로 이동합니다.

macOS에서는 읽지 않은 동일한 개수가 Dock 아이콘에 배지로 미러링되므로 Orca을 포그라운드로 가져오지 않고도 보류 중인 에이전트 핑을 확인할 수 있습니다.

## 읽지 않은 것으로 표시

읽지 않은 것으로 표시하려면 알림을 마우스 오른쪽 버튼으로 클릭하세요. 항목을 분류했지만 나중에 다시 확인하고 싶을 때 유용합니다.

## 튜닝

[설정 → 알림](/orca-docs-ko/docs/settings/)에서 특정 카테고리(시스템, 사운드, 칩 전용)를 끄세요.

## 맞춤 사운드

[설정 → 알림](/orca-docs-ko/docs/settings/)에서 카테고리별로 사용자 정의 데스크탑 알림 소리를 선택하세요. 디스크에 있는 오디오 파일을 가리키거나 Orca에 내장된 세트에서 선택하세요. 에이전트가 완료한 핑을 시스템 메일 및 Slack에서 눈에 띄게 하려는 경우에 유용합니다.

지원되는 형식: MP3, WAV, OGG, M4A, AAC, FLAC. 전달된 모든 데스크톱 알림에 하나의 파일이 적용됩니다.

사용자 정의 사운드를 사용하는 경우 동일한 설정 창에서 재생 볼륨을 설정하세요.
