Orca이 수집하는 익명의 사용 데이터, 수집하지 않는 데이터 및 수신 거부 방법.

이 페이지에서는 패키지된 Orca 빌드에서 수집하는 익명의 제품 사용량 원격 분석, 절대 수집하지 않는 항목 및 선택 해제 방법에 대해 설명합니다.

## 요약

- **익명.** 이벤트는 컴퓨터에 로컬로 저장된 임의 ID로 입력됩니다. 계정, 이메일, IP 주소 또는 사용자 이름은 수집되지 않습니다.
- **콘텐츠 없음.** 파일 콘텐츠, 프롬프트, 에이전트 출력, 터미널 출력, 저장소 이름, 브랜치 이름, URL, 경로 또는 커밋 메시지를 전송하지 않습니다.
- `Always off when:`(항상 꺼짐:) `DO_NOT_TRACK=1` 또는 `ORCA_TELEMETRY_DISABLED=1`가 설정된 경우.

## 우리가 수집하는 것

각 이벤트와 함께 Orca 버전, 운영 체제(예: `darwin` / `win32` / `linux`), CPU 아키텍처, 대략적인 OS 릴리스 문자열, 릴리스 채널(`stable` 또는 `rc`) 등 기본 빌드 및 플랫폼 정보가 포함됩니다. 위에서 설명한 익명 로컬 ID. 호스트 이름, 사용자 이름, IP가 없습니다.

우리가 관찰하는 행동의 범주는 다음과 같습니다.

- `Lifecycle`(수명주기) — 앱이 열릴 때. 일일, 주간, 월간 활성 사용자를 추정하는 데 사용됩니다.
- `Repos and workspaces`(저장소 및 작업공간) — 저장소를 추가하거나 작업공간을 생성할 때. 우리는 *어떻게* 수행했는지(예: 폴더 선택기 대 복제 URL, 명령 팔레트 대 드래그 앤 드롭) 기록하며 저장소 이름, URL, 경로, 분기 이름 또는 자유 형식 텍스트는 기록하지 않습니다.
- `Agents`(에이전트) — 에이전트를 시작할 때 해당 에이전트 종류(`claude-code`, `codex`, `gemini` 등과 같은 고정 목록에서), 에이전트를 시작한 위치. 프롬프트, 모델 세부정보 또는 에이전트 출력은 절대 사용하지 마세요.
- `Agent errors`(에이전트 오류) — 대략적인 오류 범주 및 관련된 에이전트 종류입니다. 우리는 원시 오류 메시지나 스택 추적을 볼 수 없습니다. 사건별 세부 정보는 컴퓨터의 로컬 진단 추적 파일에 유지되며 진단 번들을 명시적으로 공유하는 경우에만 Orca에 도달합니다.
- `Settings`(설정) — 화이트리스트에 포함된 기능 플래그 또는 UX 기본 설정 중 하나를 전환하는 경우입니다. 어떤 기본 설정이 변경되었는지, 부울인지 열거형인지 기록하며 자유 형식 설정의 원시 값은 기록하지 않습니다.
- `Privacy controls`(개인 정보 보호 제어) — 원격 측정을 선택하거나 선택 해제할 때 동의 UI가 작동하는지 집계 데이터를 통해 알 수 있습니다.

우리가 전송하는 모든 필드는 고정된 열거형 값, 버전 문자열 또는 익명의 로컬 ID입니다. UI 입력의 자유 형식 문자열은 컴퓨터를 떠나지 않습니다.

## 우리가 절대 보내지 않는 것

- 파일 경로, 저장소 이름, 분기 이름, URL, 커밋 메시지 또는 현재 작업 디렉터리가 없습니다.
- 상담원 프롬프트, 응답 또는 터미널 콘텐츠가 없습니다.
- 원시 오류 메시지나 스택 프레임이 없습니다. 사고별 오류 컨텍스트는 컴퓨터의 로컬 진단 추적 파일에 유지되며 진단 번들을 명시적으로 공유하는 경우에만 우리에게 도달합니다.
- 사용자 계정 정보가 없습니다(Orca에는 계정 시스템이 없습니다).
- IP 주소가 없고 정확한 지역 IP가 없습니다. 국가는 요청에서 파생된 유일한 지리적 신호입니다.
- 귀하의 익명 ID와 연결된 공급업체 측 사용자 프로필이 없습니다.

## 선택 해제 방법

세 가지 방법으로 원격 측정을 비활성화할 수 있습니다. 그 중 어느 것으로도 충분합니다. 그들은 작곡합니다.

1. **앱에서** 설정 → 개인정보 보호 → '익명 사용 데이터 공유'를 끄세요. 변화는 즉각적이고 지속적입니다.

![설정 → 개인정보 보호 - '익명 사용 데이터 공유'를 꺼서 원격 측정을 비활성화합니다.](/orca-docs-ko/assets/mirror/a5de013aa974210de83b50e5965d02a8f69fc67261fd814c7d1823b860f48e3d.png)

설정 → 개인 정보 보호 — 원격 측정을 비활성화하려면 '익명 사용 데이터 공유'를 끄세요.

2. **`DO_NOT_TRACK=1`** — 커뮤니티 표준 환경 변수. 해당 실행에 대한 전송을 비활성화합니다. 설정을 해제하면 다음 실행 시 저장된 기본 설정이 복원됩니다.
3. **`ORCA_TELEMETRY_DISABLED=1`** — `DO_NOT_TRACK`와 동일한 의미를 갖는 Orca 관련 킬 스위치입니다.

## 데이터는 어디로 가는가

- `Vendor:`(공급업체:) PostHog Cloud, `United States`(미국) 지역.
- `Retention:`(보존:) 가격 책정 페이지에 따른 PostHog Cloud의 계획 수준 기본값입니다. 우리는 사용자 정의 보존 기간을 설정하지 않습니다.
- `Access:`(액세스:) 프로젝트 멤버십은 소수의 Orca 관리자로 제한됩니다.
